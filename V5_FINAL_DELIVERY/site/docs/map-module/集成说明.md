## 1. 前置条件

| 项 | 要求 |
|---|---|
| 运行协议 | **必须** `http://` 或 `https://`；不支持 `file://`（见第 10 节） |
| 浏览器 | 支持 Custom Elements、Shadow DOM、Pointer Events、ResizeObserver 的现代浏览器；已验收环境为 **Microsoft Edge 156（headless Chromium）**，Safari/Firefox/真机触摸等未覆盖（见测试报告第 9 节） |
| 依赖 | **零依赖、零构建、无 CDN、无外部网络请求**；组件为单文件 `src/gz-district-map.js`（实现版本 `1.0.0`） |
| 数据文件 | `data/district_metrics.json`、`data/gz_districts_11.geojson`（只读，勿修改） |
| 本地预览 | `python tools\serve.py 8801` → `http://127.0.0.1:8801/demo/` |

组件由脚本自动注册自定义元素 `<gz-district-map>`（重复加载脚本有防重复定义保护），并暴露：

- `window.GzDistrictMap`：自定义元素类（`customElements.get('gz-district-map')`）；
- `window.mountGuangzhouDistrictMap(container, options)`：便捷挂载，返回实例；`options` 支持 `id`、`className`、`data`、`geometry`、`metric`、`heightMode`、`focusRule`、`labelOffsets`（已核对源码）。

## 2. 最小接入示例

把组件脚本放在元素之前，再用 JavaScript 注入两份数据。数据注入是**异步渲染**的：数据未齐时组件显示“等待数据（需同时设置 .data 与 .geometry）”占位，不报错。

```html
<!-- 1) 组件脚本：路径按宿主页相对位置调整 -->
<script src="src/gz-district-map.js"></script>

<!-- 2) 自定义元素（高度由宿主给，否则可能塌陷） -->
<gz-district-map id="gzmap" style="display:block; min-height:520px;"></gz-district-map>

<!-- 3) 注入数据（必须在 http(s) 下；路径按宿主页相对位置调整） -->
<script>
(async function () {
  await customElements.whenDefined('gz-district-map'); // 防脚本顺序问题
  const map = document.getElementById('gzmap');

  const [metrics, geometry] = await Promise.all([
    fetch('data/district_metrics.json').then(function (r) {
      if (!r.ok) throw new Error('district_metrics.json HTTP ' + r.status);
      return r.json();
    }),
    fetch('data/gz_districts_11.geojson').then(function (r) {
      if (!r.ok) throw new Error('gz_districts_11.geojson HTTP ' + r.status);
      return r.json();
    })
  ]);

  map.data = metrics;       // 必填：data/district_metrics.json 对象
  map.geometry = geometry;  // 必填：data/gz_districts_11.geojson 对象

  // 可选：默认取 meta.defaultMetric（"bedDensity"）与 meta.defaultHeightMode（"metric"）
  map.metric = metrics.meta.defaultMetric;
  map.heightMode = metrics.meta.defaultHeightMode;

  map.addEventListener('gzmap:ready', function (e) {
    console.log('[gzmap] ready', e.detail); // {districtCount: 11, metricId: "bedDensity"}
  });
})();
</script>
```

等价的便捷挂载写法（数据需已在宿主侧取得）：

```js
const map = window.mountGuangzhouDistrictMap(document.getElementById('map-slot'), {
  data: metrics,
  geometry: geometry,
  metric: 'bedDensity',
  heightMode: 'metric'
});
```

> 也可以用 HTML 属性声明 `metric="elderly60Share"`、`height-mode="flat"`（实现通过 `observedAttributes` 监听 `metric` 与 `height-mode` 两个属性）；`data`/`geometry` 只能通过 JavaScript 属性注入，没有对应的 HTML 属性。

## 3. 属性

| 属性 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| `data` | object | **是** | `null` | `data/district_metrics.json` 的完整对象；非对象或缺失时保持“等待数据” |
| `geometry` | object | **是** | `null` | `data/gz_districts_11.geojson` 的完整对象（需为带 `features` 数组的 FeatureCollection） |
| `metric` | string | 否 | `meta.defaultMetric`（`"bedDensity"`） | 当前指标 id，必须是 `metrics[].id` 之一；未知 id `console.warn` 并忽略 |
| `heightMode` | `"metric"` \| `"flat"` | 否 | `meta.defaultHeightMode`（`"metric"`） | 2.5D 高度语义：按指标 / 统一厚度；其他值 `console.warn` 并忽略 |
| `focusRule` | `null` \| `(district) => {isFocus, reason}` | 否 | `null` | 重点关注区判定函数；**当前未配置**（见第 8 节） |
| `labelOffsets` | `{ [adcode]: [dx, dy] }` | 否 | `null` | 区名标签微调（SVG 用户单位），仅影响排版 |

- HTML 属性：`<gz-district-map metric="..." height-mode="flat">` 受支持；`data`/`geometry`/`focusRule`/`labelOffsets` 需用 JS 属性赋值。
- 数值/单位/年份/小数位以 `metrics` 字段为准，组件不重算数值（重算校验已在构建阶段完成）。
- 缺失值：`values[metricId] === null`（或 `missingMetrics` 命中）必须显示“缺失”，**不得显示 0**（见第 9 节与已知限制文档）。
- 夹具提示：若 `data.meta._fixture === true`，组件会显示“测试夹具（合成）数据：仅用于演示缺失值渲染，禁止用于研究展示。”提示条；真实数据不受影响。

## 4. 方法（均已对照源码核对）

| 方法 | 参数 | 实际行为 |
|---|---|---|
| `setMetric(id)` | 指标 id | 切换指标并派发 `gzmap:metricchange`；未知 id `console.warn` 并**忽略（不抛错）**；返回 `this` |
| `setHeightMode(mode)` | `"metric"` \| `"flat"` | 切换高度语义；非法值 `console.warn` 并忽略；返回 `this` |
| `select(adcode, opts?)` | adcode 或 `null`；`opts.source` 默认 `"api"` | 选中/清空并派发 `gzmap:select`；未知 adcode `console.warn` 并忽略；返回 `this` |
| `highlight(adcode)` | adcode 或 `null` | 外部悬停高亮（如条形图 hover），**不等于选中**；不派发事件；返回 `this` |
| `resetView()` | — | 恢复默认 viewBox 并清空选中（保留当前指标）；若原先有选中，会先派发 `gzmap:select`（`adcode:null, source:"api"`），再派发 `gzmap:reset`；返回 `this` |
| `resetAll()` | — | 恢复默认指标 + 默认高度 + 默认视图 + 清空选中；指标变化时派发 `gzmap:metricchange`，并派发 `gzmap:reset`；返回 `this` |
| `focusDistrict(adcode)` | adcode | 键盘/无障碍焦点移到某区；未知 adcode `console.warn` |
| `getState()` | — | 返回 `{metricId, heightMode, selected, viewBox, focusDistricts, missingCount}`；`selected` 为 adcode 字符串或 `null`，`viewBox` 为 `[x,y,w,h]` |
| `destroy()` | — | 取消动画帧/定时器、断开 ResizeObserver、清空 Shadow DOM；多实例或 SPA 路由切换时调用 |

> 所有方法均返回 `this`（除 `getState()`），可链式调用；`destroy()` 后调用其他方法为空操作。

## 5. 事件

事件均为 `CustomEvent`，`bubbles: true, composed: true`（可穿透 Shadow DOM 冒泡到宿主）。

| 事件 | `detail` | 触发时机 |
|---|---|---|
| `gzmap:ready` | `{districtCount, metricId}` | 数据齐备并完成首帧渲染（仅派发一次） |
| `gzmap:select` | `{adcode, name, metricId, value, source}`；清空选中时 `adcode: null` | 地图点击/键盘选中、`select()`、`resetView()` 清空选中 |
| `gzmap:hover` | `{adcode\|null, name, value, clientX, clientY}` | 悬停进入/离开区（离开时 `adcode: null`） |
| `gzmap:metricchange` | `{metricId, metric}` | 指标切换（用户点击/属性变化/`setMetric`/`resetAll`） |
| `gzmap:viewchange` | `{viewBox: [x, y, w, h], zoom}`，节流 100ms | 缩放/平移后 |
| `gzmap:reset` | `{metricId, clearedSelection}` | `resetView()` / `resetAll()` |

**`detail.source` 的语义（防回环的关键）**：

- 地图自身交互（点击区、键盘选中、点击空白清空）派发 `source: "map"`；
- 宿主调用 `select(code)` 时，组件派发 `gzmap:select` 且 `source: "api"`（默认值）；
- `resetView()` 清空选中时派发的 `gzmap:select` 也是 `source: "api"`（这是组件内部清空，不是地图点击）；
- 宿主监听 `gzmap:select` 时，只处理 `source === "map"` 的方向（地图 → 宿主）；`source === "api"` 表示“本次变化来自宿主/组件 API”，宿主的联动逻辑应跳过，避免 A→B→A 回环。

### 5.1 真实指针 / 触摸行为（冻结版已修复 DEF-01）

- 冻结版修复了一个 P0 缺陷（DEF-01）：此前 `pointerdown` 立即 `setPointerCapture` 会把后续 `click` 重定向到 `<svg>`，导致**真实鼠标单击地图区无法选中**（页面内合成 `click` 测不出来）。修复后：仅在位移超过拖拽阈值、确认进入拖拽后才捕获指针，并以“按下命中的区 + 位移 <5px”作为 click 的回退判定。
- 拖拽/双指捏合结束后约 **400ms 的 click 抑制窗口**：窗口内的 click 被忽略，避免拖拽结束误选/误清空。宿主无需特殊处理，也不要在此期间用脚本强制补发 click。
- 该行为已由真实输入 E2E 回归：C1/C1b（`Input.dispatchMouseEvent` 真实点击 4 个区）、D5（以区为起点真实拖拽后不误选、抑制窗口后点击恢复）、J4（`Input.dispatchTouchEvent` 触摸点按选中）均通过。**“页面内合成 click”不能作为点击可用的证据**，验收请以 `tests/e2e.cjs` 为准。

## 6. 宿主条形图双向联动示例

> 以下条形图为**示例代码**，用于说明事件联动方式；它不是报告正式图表，也不代表宿主已有该图表。样式与布局需按宿主页面调整。

```html
<div id="bar-panel" aria-label="11 区横向条形图（示例联动）"></div>

<script>
(function () {
  const mapEl = document.getElementById('gzmap');
  const panel = document.getElementById('bar-panel');
  let metricsData = null; // 保存 data/district_metrics.json 对象，供标题/单位/年份使用

  function metricMeta(metrics, id) {
    return metrics.metrics.find(function (m) { return m.id === id; });
  }

  function renderBars() {
    if (!metricsData) return;
    const m = metricMeta(metricsData, mapEl.metric);
    const rows = metricsData.districts
      .map(function (d) {
        return { adcode: d.adcode, name: d.name, value: d.values[m.id] };
      })
      // 缺失值不参与排序（null 放最后，显示“缺失”）
      .sort(function (a, b) {
        if (a.value === null) return 1;
        if (b.value === null) return -1;
        return b.value - a.value;
      });

    const max = Math.max.apply(null, rows
      .filter(function (r) { return r.value !== null; })
      .map(function (r) { return r.value; }));

    panel.innerHTML = '';
    const title = document.createElement('h3');
    title.textContent = m.label + ' · ' + m.years + '（示例联动，非报告正式图表）';
    panel.appendChild(title);

    rows.forEach(function (r) {
      const row = document.createElement('button');
      row.type = 'button';
      row.className = 'bar-row';
      row.dataset.adcode = r.adcode;
      row.setAttribute('aria-label',
        r.name + ' ' + (r.value === null ? '缺失' : r.value + m.unit));

      const label = document.createElement('span');
      label.className = 'bar-label';
      label.textContent = r.name;

      const track = document.createElement('span');
      track.className = 'bar-track';
      const fill = document.createElement('span');
      fill.className = 'bar-fill';
      fill.style.width = r.value === null ? '0%'
        : Math.max(2, (r.value / max) * 100).toFixed(2) + '%';
      track.appendChild(fill);

      const val = document.createElement('span');
      val.className = 'bar-value';
      val.textContent = r.value === null ? '缺失'
        : r.value.toFixed(m.decimals) + ' ' + m.unit;

      row.appendChild(label);
      row.appendChild(track);
      row.appendChild(val);

      // 条形图 → 地图：source 必须传 "api"（默认即 "api"，显式写更清楚）
      row.addEventListener('click', function () {
        mapEl.select(r.adcode, { source: 'api' });
      });
      // 条形图悬停 → 地图高亮（可选）
      row.addEventListener('mouseenter', function () { mapEl.highlight(r.adcode); });
      row.addEventListener('mouseleave', function () { mapEl.highlight(null); });

      panel.appendChild(row);
    });
  }

  // 地图 → 条形图：只响应“地图自身”的选中，跳过 API 来源以防回环
  mapEl.addEventListener('gzmap:select', function (e) {
    const detail = e.detail;
    if (detail.source !== 'map') return;

    panel.querySelectorAll('.bar-row').forEach(function (row) {
      const on = row.dataset.adcode === detail.adcode;
      row.classList.toggle('is-selected', on);
      row.setAttribute('aria-pressed', on ? 'true' : 'false');
      if (on) row.scrollIntoView({ block: 'nearest', behavior: 'smooth' });
    });
  });

  // 指标切换：重建条形图（标题/单位/年份随之更新）
  mapEl.addEventListener('gzmap:metricchange', renderBars);

  // 首次加载：在 ready 后使用已注入的数据渲染条形图
  mapEl.addEventListener('gzmap:ready', function () {
    fetch('data/district_metrics.json')
      .then(function (r) { return r.json(); })
      .then(function (json) { metricsData = json; renderBars(); });
  });
})();
</script>
```

**联动方向与 source 约定速查**：

| 方向 | 触发 | 宿主动作 | 事件/参数 |
|---|---|---|---|
| 地图 → 条形图 | 用户点区/键盘选中 | 高亮对应条形、滚动到可见 | 监听 `gzmap:select`，仅处理 `detail.source === "map"` |
| 条形图 → 地图 | 用户点条形 | 地图选中 + 详情更新 | `map.select(adcode, { source: "api" })` |
| 地图 → 条形图 hover（可选） | 悬停区 | 条形 hover 样式 | 监听 `gzmap:hover`（`adcode: null` 表示移出） |
| 条形图 → 地图 hover（可选） | 悬停条形 | 地图高亮（非选中） | `map.highlight(adcode)` / `map.highlight(null)` |
| 指标切换 | 用户切指标 | 重建条形图标题/单位/年份 | 监听 `gzmap:metricchange` |
| 重置视图 | 用户点“重置视图” | 清空条形图选中态 | 监听 `gzmap:reset`（`clearedSelection` 表示是否曾有选中） |

> 注意：`select()` 会让组件再派发一次 `source: "api"` 的 `gzmap:select`；示例在监听器里直接返回，因此不会回写条形图，也不会形成回环。另外点击地图空白区域会以 `source: "map"` 清空选中（`adcode: null`），示例 listener 会把所有条形取消高亮，这属于预期行为。

## 7. 数据注入与读取顺序

1. 先确保 `<script src="src/gz-district-map.js">` 执行（自定义元素注册）。
2. 创建/获取 `<gz-district-map>` 元素。
3. 并行 `fetch` 两个数据文件，任一失败要能在宿主侧提示（组件显示占位不报错）。
4. 先赋 `data` 再赋 `geometry`（或反之），两者齐备后组件渲染；可监听 `gzmap:ready` 判断就绪。
5. 设置 `metric` / `heightMode` 可放在赋值前或后；组件按属性异步渲染。

宿主若已有全局数据层（如从 `window.__DATA__` 注入），直接传对象即可；不要修改 JSON 文件内容，也不要在宿主侧重算指标。

## 8. `focusRule` 接口（当前未配置）

el.focusRule = function (district) {

**当前状态**：`meta.focus.status = "not_configured"`、`ruleId = null`、`sourceRef = null`。工作区未检出报告既有判定规则，因此：

- 默认必须为 `null` 或返回 `{isFocus:false}`，**不得标注任何“重点关注区”**；
- 未配置时界面显示“重点关注区规则未配置，本图不标注”；
- 如需演示接口，只能使用显著标注“接口演示，非报告结论”的示例开关，且**默认关闭**；
- 正式规则必须由报告作者提供（阈值、指标组合、时点、数据来源），接入后在报告与图注中注明规则出处。

> 不要在宿主页里自拟“床位密度高于/低于某值即重点关注”一类规则，这会被误读为报告结论。

## 9. 样式隔离与主题变量（已核对源码）

- 组件使用 **Shadow DOM（`mode:"open"`）** 封装全部样式：宿主全局 CSS 不会影响组件内部，组件样式也不外泄。
- 宿主可给 `<gz-district-map>` 设置尺寸（如 `display:block; min-height:520px;`）；组件根节点 `div.gz` 带 `part="root"`，宿主可用 `gz-district-map::part(root) { ... }` 做有限外部样式调整。
- **CSS 变量（实现已在 `:host` 声明默认值）**：

| 变量 | 默认值 | 用途 |
|---|---|---|
| `--gz-line` | `#d3dae3` | 边框/分隔线 |
| `--gz-ink` | `#1b2430` | 主文字色 |
| `--gz-muted` | `#5b6675` | 次要文字色 |
| `--gz-accent` | `#1f5f97` | 强调色/焦点轮廓/选中下划线 |
| `--gz-accent-ink` | `#0f3f66` | 强调态文字色 |
| `--gz-accent-soft` | `#eaf2fa` | 强调态浅底 |
| `--gz-warn-bg` | `#fff7e6` | 警告条底色 |
| `--gz-warn-line` | `#e9c07a` | 警告条边框 |
| `--gz-warn-ink` | `#7a4a06` | 警告条文字色 |

宿主主题化示例（只覆盖公开变量，不穿透 Shadow DOM）：

```css
gz-district-map {
  --gz-accent: #0b6b5b;
  --gz-accent-ink: #064a3f;
  --gz-accent-soft: #e6f4f1;

```

- 不要用宿主选择器直接改组件内部元素（如 `.district`、`.legend`，它们在 Shadow DOM 外不可选中）；不要给内部元素设 `!important`；不要用 `aria-hidden` 包裹地图或覆盖其焦点样式。
- 无障碍：组件自带键盘操作、`aria-label` 与 `aria-live` 播报；`prefers-reduced-motion` 下会关闭过渡。
- z-index/溢出：tooltip 与详情面板可能在容器边缘裁切；宿主容器需允许必要的 `overflow: visible` 或为地图留足内边距（以实际渲染为准，待联调）。

## 10. `http://` 运行限制与 `file://` 不支持

- 组件本身不发起网络请求；但**数据加载由宿主/演示页通过 `fetch` 完成**，因此页面必须经 `http(s)` 提供。浏览器对 `file://` 页面的 `fetch` 有严格限制（通常直接失败，`origin` 为 `null`），**双击打开 `demo/index.html` 会看不到地图数据**，组件停留在“等待数据”占位。
- 正确方式：启动本地静态服务器后访问 `http://127.0.0.1:<端口>/...`：

```powershell
cd D:\筑工杯数据获取\广州11区交互地图模块_20261028
python tools\serve.py 8801
# 浏览器打开：http://127.0.0.1:8801/demo/
```

- 若宿主页运行在 `https://`，需把 `src/gz-district-map.js` 与 `data/*.json|geojson` 部署到**同一可访问路径**，并确保 MIME 类型正确（`application/json`、`application/geo+json`）；跨域部署需宿主配置 CORS。
- `tools/serve.py` 仅用于本地预览与测试，**不是生产服务器**。

## 13. 故障排查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 页面空白/一直“等待数据” | 用 `file://` 打开；或 fetch 路径错误；或只设置了 `data` 或 `geometry` 之一 | 改用 `python tools\serve.py`；检查 Network 中 JSON 是否 200；两个属性都要设置 |
| 控制台 `[gz-district-map] 未知指标 id` | 设置了 `metrics` 中不存在的 `metric` | 从 `metrics[].id` 动态取值 |
| `map.data = ...` 后不渲染 | 赋值发生在元素注册前被忽略，或 `geometry` 未赋 | 用 `customElements.whenDefined` 后再赋值；确保两个属性都设置 |
| 条形图点击后地图又反向触发条形图 | 监听器未过滤 `detail.source` | 只在 `detail.source === 'map'` 时更新条形图；条形图点击传 `{source:'api'}` |
| 点击地图空白处条形图选中被清空 | 这是组件预期行为 | 监听 `gzmap:select`，`adcode:null` 时清空条形图即可 |
| 拖拽/双指结束后立即点击没反应 | 冻结版在拖拽/捏合结束后有约 400ms 的 click 抑制窗口（防拖拽误选，DEF-01 修复的一部分） | 等待约 0.4s 再点击；这是预期设计，不是缺陷 |
| 组件样式被宿主全局样式影响 | 宿主用了 `*`/`button` 等全局选择器，或改了组件宿主元素尺寸 | 依赖 Shadow DOM 隔离；主题化只用第 9 节的 CSS 变量 / `::part(root)` |
| 移动端 tooltip 被裁切 | 容器 overflow/z-index | 调整宿主容器内边距与层级；以实际渲染验证 |
| 截图缺图例/免责声明 | 截图范围过小 | 按 1440×900 或 390×844 全页截图，保留页脚 |

# 内部规格：广州 11 区交互地图组件契约（v1.0）

> 本文件是给实现方与验收方使用的**冻结契约**，不是对外交付说明。
> 数据契约以 `data/district_metrics.json`、`data/gz_districts_11.geojson` 为准（由 `tools/build_data.py` 生成，264/264 项校验通过）。

## 1. 目标与边界

为报告《从场景清单到审慎试点：广州市人工智能养老应用的需求匹配、证据成熟度与推广条件研究》制作**独立的广州 11 区 2.5D 交互地图组件**，服务区级供给结构分析。

必须遵守：

1. 只呈现**区级**数据；不生成街镇级需求热力图。
2. 床位密度等是**供给密度代理**，不等于服务能力、可达性、需求满足率；不得解释为养老需求或供需匹配程度。
3. 不呈现因果结论；相关不等于因果。
4. **不得预设“重点关注区”**：`meta.focus.status = not_configured`，组件只提供 `focusRule` 接口。没有规则就显示“未配置”，不得主观挑选。
5. 缺失数据（`null`）必须显示为“缺失”，**绝不以 0 代替**。
6. 不修改 `data/` 下任何文件；不联网；不引入第三方依赖；不影响宿主页面样式。
7. 不修改其他执行方文件；本模块写入范围见第 10 节。

## 2. 数据契约（只读）

### 2.1 `data/district_metrics.json`

```
{
  meta: {
    schemaVersion, reportTitle, city, level:"district", districtCount:11,
    generatedAt, defaultMetric:"bedDensity", defaultHeightMode:"metric",
    boundary: {file, sourceName, sourceUrl, retrievedAt, sha256Original, license, crs, geometryQA, disclaimer},
    populationSource, facilitySource, derivedTable,
    focus: {status:"not_configured", ruleId, sourceRef, note},
    hostPage: {status:"not_found_in_workspace", note},
    missingData: {principle, notAvailable:[...], note},
    boundariesOfUse: [string]
  },
  metrics: [{
    id, label, shortLabel, unit, years, numerator, denominator,
    decimals, primary:boolean, group?: "sensitivity",
    source, qualityNote
  }],
  cityTotals: { raw:{...}, values:{...}, note },
  districts: [{
    adcode:"440103", name:"荔湾区",
    values: { bedDensity:number, institutionDensity, mealDensity, primaryCareDensity,
              elderly80Share, elderly60Share, elderly65Share, bedDensitySensitivity } | null,
    raw: { totalPopulation2025, population60Plus2025, population65Plus2025, population80Plus2025,
           population60Plus2020, registeredBeds2026, eldercareInstitutions2026,
           elderCareMealSites2025, primaryCareInstitutions2023 },
    areaKm2Geometric:number, flags:[string], missingMetrics:[string]
  }],
  checks: [...]
}
```

- 指标顺序即 UI 建议顺序；`primary` 为默认展示组（4 个），其余放“更多指标”。
- `values[metricId]` 为 `null` 表示缺失；`missingMetrics` 为冗余提示，两处都要处理。
- 数值仅用于显示；**不要重算**（重算校验已在 build 阶段完成）。
- `decimals` 为显示小数位；`unit` 必须逐字展示（含“每千名/每万名 60+”）。
- `years` 必须逐字展示（如“床位 2026-09；人口 2025 年末”）。
- 敏感性指标 `bedDensitySensitivity` 带 `group: "sensitivity"`，不得与主指标混用排名，UI 放在“更多指标”并加“口径对照”标签。

### 2.2 `data/gz_districts_11.geojson`

- `FeatureCollection`，11 个 `MultiPolygon`，每个 1 个外环、无内环。
- `properties`: `adcode`, `name`, `center:[lng,lat]`, `centroid:[lng,lat]`, `areaKm2Geometric`。
- 坐标为原始经纬度（坐标系未声明，**仅示意**）。**不得叠加任何底图/瓦片**。
- `source` 内含来源、许可、免责声明，UI 需在页脚或“数据说明”中呈现关键句。

### 2.3 测试夹具 `data/_fixture_missing.json`

- 与真实数据结构相同，但海珠区、从化区 `bedDensity=null`，南沙区 `elderly80Share=null`，`meta._fixture=true`。
- 仅供测试/演示缺失值渲染，**必须显示“测试夹具（合成）”标识**，禁止用于研究展示。

## 4. 组件公共 API（必须实现）

### 4.1 注册与挂载

```html
<script src="src/gz-district-map.js"></script>
<gz-district-map id="gzmap"></gz-district-map>
```

- 脚本执行后自动 `customElements.define('gz-district-map', ...)`（重复加载需防重复定义）。
- 同时暴露 `window.GzDistrictMap`（类）与 `window.mountGuangzhouDistrictMap(container, options)`（便捷挂载，返回实例）。
- 属性/属性方法（二选一均可，必须两种都支持）：
  - `el.data = metricsJson`（对象；必填）
  - `el.geometry = geojson`（对象；必填）
  - `el.metric = "bedDensity"`（可选，默认 `meta.defaultMetric`）
  - `el.heightMode = "metric" | "flat"`（可选，默认 `meta.defaultHeightMode`）
  - `el.focusRule = null | (district) => ({isFocus:boolean, reason:string})`（可选）
  - `el.labelOffsets = { "440103": [dx,dy], ... }`（可选，SVG 用户单位）
- 属性设置后异步渲染；数据未齐时显示“等待数据”占位，不得报错。

### 4.2 方法

| 方法 | 说明 |
|---|---|
| `setMetric(id)` | 切换指标；未知 id 抛错/忽略并 console.warn |
| `setHeightMode('metric'\|'flat')` | 切换 2.5D 高度语义 |
| `select(adcode\|null, opts?)` | 选中/清空；`opts.source` 默认 `"api"`，用于事件回传来源 |
| `highlight(adcode\|null)` | 外部悬停高亮（如条形图 hover），不等于选中 |
| `resetView()` | 恢复默认 viewBox 与选中状态（保留当前指标） |
| `resetAll()` | 恢复默认指标 + 默认高度 + 默认视图 + 清空选中 |
| `focusDistrict(adcode)` | 键盘/无障碍焦点移到某区 |
| `getState()` | 返回 `{metricId, heightMode, selected, viewBox, focusDistricts, missingCount}` |
| `destroy()` | 移除监听、清空 Shadow DOM |

### 4.3 事件（CustomEvent，`bubbles:true, composed:true`）

| 事件 | detail |
|---|---|
| `gzmap:ready` | `{districtCount, metricId}` |
| `gzmap:select` | `{adcode, name, metricId, value, source}`；清空选中时 `adcode:null` |
| `gzmap:hover` | `{adcode|null, name, value, clientX, clientY}` |
| `gzmap:metricchange` | `{metricId, metric}` |
| `gzmap:viewchange` | `{viewBox:[x,y,w,h], zoom}`（节流 ≥100ms） |
| `gzmap:reset` | `{metricId, clearedSelection}` |

- 外部调用 `select(code)` 必须派发 `gzmap:select` 且 `detail.source === "api"`，供条形图区分避免回环。
- 地图点击派发 `detail.source === "map"`。

## 5. 视觉与 2.5D 渲染

### 5.1 总体布局（组件内部，Shadow DOM）

- 顶部：标题“广州市 11 区养老供给结构（区级）”+ 副标题“数据：2025 户籍人口 / 2026-09 养老机构名录”（可用 `meta`）。
- 指标选择：桌面端胶囊按钮组（8 个指标分两行：4 个 primary + “更多指标”展开/或全部平铺）；移动端用横向滚动胶囊或 `<select>`。选中态必须有非颜色线索（边框/下划线）。
- 高度模式开关：`2.5D 高度：按指标 / 统一`（默认“按指标”）；切换时图例说明同步变化。
- 重置按钮：“重置视图”。
- 主体：SVG 地图 + 右侧详情面板（桌面 ≥ 900px：地图约 62%，面板约 38%；移动端：地图在上、面板在下）。
- 图例在 SVG 下方或面板上方，始终可见，包含：指标全名、`years`、`unit`、连续色带（含最小/最大值刻度、11 区中位数刻度）、高度说明、缺失色块（仅当该指标有缺失时）、来源一行、口径提示。
- 页脚：`仅区级数据；供给密度为代理指标，不代表服务需求、服务能力或供需匹配程度。边界非官方勘定界线，仅作示意。`

### 5.2 投影与 2.5D

- 投影：局部等距圆柱（`x ∝ lng·cos(meanLat)`，`y ∝ -lat`），等比适配 viewBox，留白 ≥ 32 用户单位；无底图、无瓦片。
- 2.5D 挤出：
  - `heightMode="metric"`：`h = hMin + sqrt(norm)·(hMax-hMin)`，`norm=(value-min)/(max-min)`；`hMin≈2`、`hMax≈34`（以 viewBox 高度 1000 为基准，可调）；同一指标内高度与颜色**表达同一指标**。
  - `heightMode="flat"`：所有区统一厚度 `h≈6`（纯视觉层次，**不表示指标**）。
- 绘制：每区 1 个顶面 path + 1 个侧面 path（多条四边形合并为单 path）；侧面颜色为顶面颜色加深（约 30–38%）；顶面描边 0.8–1.2 用户单位。
- 排序：按各区最大 y 升序绘制（北→南），保证近处压远处；标签层与选中描边层最后绘制。
- 悬停：该区整体上浮 5–7 用户单位（120–160ms 过渡），顶面提亮，光标 pointer；显示 tooltip（区名 + 指标值 + 单位 + “点击查看详情”）。
- 标签：区名放在 `centroid`（若压边或重叠可微调 `labelOffsets`），字号按 viewBox 定（约 15–18 用户单位），白描边 halo（`paint-order: stroke`），保证在深浅底色上都可读；标签不参与点击。
- 颜色：
  - 每指标使用**单色相顺序色带**（5–7 个停靠点线性插值），色带两端与图例一致；浅色底配深色文字，深色底配白字。
  - 不用红绿对立色；不得用颜色同时表达第二个变量。
  - 选中：2.5–3 用户单位高对比描边（如深蓝/黑）+ 外发光；悬停：描边加粗。
  - 缺失：斜线 hatch 图案（`<pattern>`，深灰斜线 + 浅灰底）+ 虚线描边，**无挤出高度**。

### 5.3 详情面板

未选中：显示引导语 + 当前指标说明 + “数据边界”3 条。

选中后：
1. 区名 + `adcode`；
2. 当前指标大数值 + 单位 + `years`；
3. 全部指标小表（8 项，按 `metrics` 顺序；`null` 显示“—（缺失）”；敏感性指标加“口径对照”标签）；
4. 原始计数表：户籍总人口、60+/65+/80+ 人口、备案床位、养老机构数、饭堂点数、基层医疗机构数、几何面积（附“面积含水域/待核”提示）；
5. 质量提示（`flags`，逐条）；
6. 数据来源与口径（`metric.source`、`qualityNote`）；
7. 若 `focusRule` 返回 `isFocus`，显示“重点关注区”徽标 + `reason`；否则不显示（未配置时页脚显示“重点关注区规则未配置，本图不标注”）。

### 5.4 缩放/平移

- 滚轮以指针为中心缩放（1.08–1.2/档，范围 1×–6×）；拖拽平移（Pointer Events + `setPointerCapture`）；双指捏合缩放；移动端单指拖拽平移。
- 放大/缩小/重置按钮；双击放大；`Esc` 清空选中并聚焦地图。
- 平移边界限制：不得把内容拖出可视区超过 25%。
- `resetView()` 后 viewBox 恢复初始值，清空选中，派发 `gzmap:reset`。

## 6. 缺失数据行为（硬性）

1. 地图：hatch + 虚线，无高度，`aria-label` 含“数据缺失”，tooltip 显示“缺失（无数据，非 0）”。
2. 图例：出现“缺失数据（非 0）”色块与说明。
3. 顶部提示条（仅当该指标存在缺失）：“本指标有 N 个区缺失数据：海珠区、从化区。缺失不等于 0。”
4. 详情：显示“—（缺失）”，不得显示 0、不得插值。
5. 缺失区不参与颜色 min/max 计算；若所有区都缺失，显示空状态而非报错。
6. 切换指标后缺失状态必须即时更新。

## 7. 无障碍与键盘

- 每个区 `<g role="button" tabindex="0" aria-label="海珠区，备案床位密度（每千名60+老人）19.1 床/千名60+，床位 2026-09；人口 2025 年末">`。
- 键盘：Tab 进入图内首个区；方向键在区之间移动焦点（按数据顺序或空间最近邻，需保证 11 区都可达）；Enter/Space 选中；Esc 清空选中。
- 焦点可见：高对比描边（与选中态可区分）。
- 控件：按钮/开关有 `aria-label` / `aria-pressed`；图例文字对比度 ≥ 4.5:1。
- 选中变化通过 `aria-live="polite"` 区域播报。
- 不依赖悬停才能获取信息：点击/键盘均可打开详情。

## 8. 响应式与性能

- 断点：≥ 900px 双栏；< 900px 单栏。
- 移动端（375–430px 宽）：地图最小高度 300px；控件触控目标 ≥ 36×36px；指标选择横向滚动；详情在下方，不遮挡地图；tooltip 不被裁切。
- 支持窗口 resize/容器变化（ResizeObserver 重算 viewBox）。
- 初始渲染（11 区、2,640 顶点）桌面 < 300ms；指标切换 < 150ms；悬停帧率流畅。
- 不产生明显布局抖动（CLS）；SVG 文本不可被浏览器默认字体替换导致溢出（使用系统字体栈）。

# V5 地图集成候选（独立分支，未发布）

本目录是《从场景清单到审慎试点：广州 AI 养老研究》的 V5 候选网页源码。

## 运行

需要 Node.js 18+：

```powershell
cd site
npm run dev
# 打开 http://localhost:3000/#s-4-1
```

离线包在上级目录，双击 `start-local.bat` 即可启动本地服务并打开 4.1。
不要直接双击 `dist/index.html`，浏览器会阻止本地 `fetch()`。

## V5 内容

- 第 4 章 4.1 已接入原 `gz-district-map` v1.0.0 2.5D 地图；
- 11 区、8 指标、2.5D 高度/颜色、区详情、地图↔条形双向联动、滚轮/按钮缩放、拖拽平移、重置、键盘与移动端；
- 原非地理比较面板不再存在（地图替代其位置）；
- 第 2 章区位图、第 4 章原 V3 床位图、五章正文、41 子标题、19 文献、4 原图保留；
- 交互入口（`summary` 展开行）已加大点击区/图标/悬停焦点/展开状态。

## 边界数据与审核（重要）

- 本候选**不恢复**原 DataV GeoJSON；边界层改为 **OpenStreetMap contributors**（Nominatim lookup，ODbL 1.0），组件/指标/交互沿用原地图。
- 边界来源、OSM relation ID、许可、坐标系声明与审核状态见 `docs/BOUNDARY_SOURCE_OSM.md`。
- **地图审核/审图号尚未取得**；OSM 边界非官方勘定界线，坐标按 OSM 的 WGS84 记录，未与官方标准画法图独立核验。
- 本分支**仅供内部评审/离线验收，未部署、未合并 main**；公开或正式提交前需完成地图审核判断。不得把本候选称为“已审核”或“官方边界”。

## 验证

```powershell
npm run check
```

需 Python3；Windows 的 UTF-8/Python 环境见离线包测试记录。本分支的实际浏览器测试/截图在上级 `TEST_RESULTS/`。

## 数据边界

备案床位 2026-09 ≠ 可用床位；2025 户籍 60+ 跨年分母；设施数量 ≠ 服务能力；2 条机构区划冲突、2 组饭堂同址、基层医疗 2023-11。地图不用于推广优先级、因果或街镇供需匹配；`focusRule=null`，不标重点区。

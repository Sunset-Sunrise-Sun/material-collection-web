# V5.2 定向修订候选

本目录是《从场景清单到审慎试点：广州 AI 养老研究》的 V5.2 离线网页。

## 运行

```powershell
cd site
npm run dev
# 或解压包后双击 start-local.bat
```

离线打开需通过本地 HTTP 服务，不要直接双击 `dist/index.html`。

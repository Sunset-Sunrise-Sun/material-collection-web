# V5.1 排版候选（独立分支，未发布）

本目录是《从场景清单到审慎试点：广州 AI 养老研究》的 V5.1 候选网页源码。

## 运行

需要 Node.js 18+：

```powershell
cd site
npm run dev
# 打开 http://localhost:3000/#s-4-1
```

离线包在上级目录，双击 `start-local.bat` 启动本地服务并打开 4.1。
不要直接双击 `dist/index.html`，浏览器会阻止本地 `fetch()`。

## V5.1 内容

- 第 4 章 4.1 保留原 `gz-district-map` 2.5D 地图：11 区、8 指标、2.5D 高度/颜色、区详情、地图↔条形联动、滚轮/按钮缩放、拖拽平移、重置、键盘与移动端。
- 4.1 改为「地图 + 精简区级概览」并排、完整详情全宽位于下方；完整详情仍由同一地图组件的面板投影生成，不复制状态模型。
- 全站图表默认展示：探索性散点图（image1）默认展开；床位密度图、相关统计、年度图与报告原图直接可见；长篇补充正文仍可折叠。
- 原有正文、解释文字、统计口径、图例、数据来源和质量提示未改写；仅调整容器/展开状态。
- 交互入口沿用 V5 的 ≥44px `summary` 增强。

## 边界数据与审核（重要）

- 本候选不恢复原 DataV GeoJSON；边界层为 **OpenStreetMap contributors**（Nominatim lookup，ODbL 1.0），组件/指标/交互沿用原地图。
- **地图审核/审图号尚未取得**；OSM 边界非官方勘定界线，坐标按 OSM 的 WGS84 记录，未与官方标准画法图独立核验。
- 本分支仅供内部评审/离线验收，未部署、未合并 main；公开或正式提交前需完成地图审核判断。不得称“已审核”或“官方边界”。

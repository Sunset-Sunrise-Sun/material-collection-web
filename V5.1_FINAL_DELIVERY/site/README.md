# V5.1 修订候选（独立分支，未发布）

本目录是《从场景清单到审慎试点：广州 AI 养老研究》的 V5.1 候选网页源码。

## 运行

需要 Node.js 18+：

```powershell
cd site
npm run dev
# 打开 http://localhost:3000/#s-4-1
```

离线包在上级目录，双击 `start-local.bat` 启动本地服务并打开 4.1。
不要直接双击 `dist/index.html`，浏览器会阻止本地 `fetch()`。
